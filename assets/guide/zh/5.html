Transformer：注意力让每个 token 按相关性汇聚上下文

对应图 #5 · 第一章「大模型如何训练」

概述

2017 年的《Attention Is All You Need》提出 Transformer：去掉循环和卷积，完全依靠注意力建模序列。今天的 LLM 基本都是它的仅解码器（decoder-only）变体：一摞相同的层，每层包含「因果自注意力」和「前馈网络（FFN）」两个子层，配合残差连接与归一化。注意力的作用是让每个位置按相关性从前文中汇聚信息，FFN 则对每个位置独立做非线性变换，被普遍认为承担了大量「知识存储」。

核心机制

1. 缩放点积注意力：

Attention(Q,K,V)=softmax(dk​​QK⊤​+M)V

其中 Q=XWQ​, K=XWK​, V=XWV​。除以 dk​​ 防止点积过大导致 softmax 饱和。M 是因果掩码：未来位置取 −∞，保证第 t 个 token 只能看到 ≤t 的位置，这正是自回归训练能并行的原因。

2. 多头注意力。 把 d 维拆成 h 个头，各自计算注意力后拼接再投影，让不同头关注不同关系。

3. KV 头的共享。 多查询注意力（MQA）让所有 query 头共享一组 K/V，大幅加速解码；分组查询注意力（GQA）折中为若干组共享，质量接近多头、速度接近 MQA。Llama 3 的 8B/70B/405B 都只用 8 个 KV 头。

4. 现代组件。 相对原版，主流 LLM 普遍采用：

  • Pre-norm + RMSNorm：只做均方根缩放，计算更省。
  • SwiGLU FFN：门控线性单元变体，在相同计算量下效果更好。
  • RoPE 位置编码。

5. 复杂度与 FlashAttention。 标准注意力的时间和显存都与序列长度成平方关系。FlashAttention 不改变数学结果（精确注意力），而是用分块（tiling）减少 GPU 高带宽显存（HBM）与片上 SRAM 之间的读写；论文报告在 GPT-2（序列长 1K）上端到端训练提速 3 倍。FlashAttention-2 进一步改进并行与工作划分。

工程实践与数字

Llama 3 的超参数（表 3）是现代稠密 Transformer 的典型样本：

规模 层数 隐藏维度
8B 32 4,096
70B 80 8,192
405B 126 16,384

三者都用 SwiGLU、RoPE（θ=500,000）、128K 词表和 8 个 KV 头。

实践要点：

  • 长上下文的瓶颈不仅是注意力计算，还有 KV Cache 显存，GQA 直接把它缩小为 nkv​/nheads​。
  • 训练和推理框架（PyTorch SDPA、vLLM 等）默认集成了 FlashAttention 类内核，自研时优先复用。

常见误区

  • 「注意力权重就是模型的解释。」 注意力分布只反映信息路由的一部分，不能直接等同于因果解释。
  • 「上下文窗口越长，模型就都能用上。」 窗口长度是架构和训练上限，实际利用效果需要单独评测。
  • 「FlashAttention 是近似算法。」 它是精确注意力，只是计算顺序和访存方式不同。
