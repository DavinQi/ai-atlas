常见误区澄清：看起来像，不等于就是

对应图 #9 · 第一章「大模型如何训练」

概述

图中列出了三个最常见的误解：「模型像人脑一样理解和思考」「模型把所有书原文存了进去」「模型训练完还会自动学新知识」。本文逐条说明研究证据支持什么、不支持什么。需要提前说明：第一条涉及「理解」的定义，学界至今仍有争论；本文只陈述可以被实验验证的机制层面的事实，不对哲学问题下结论。

核心机制

误区一：「像人脑一样理解、思考」

机制事实。 LLM 的训练目标是最小化下一个 token 的交叉熵 −∑t​logpθ​(xt​∣x<t​)。生成时，模型逐个输出 token 的概率分布，再按解码策略采样。所谓「思考」，在推理模型里体现为先生成一段思维链，再给出答案。思维链提示能显著提升多步推理表现；DeepSeek-R1 用强化学习让模型自发产生更长的思维链和自我检查行为。

应该怎么理解。 「只是预测下一个 token」描述的是训练目标和输出接口，并不说明模型内部表征的复杂程度：要把下一个 token 预测准，模型必须学到大量语法、事实和推理模式。另一方面，模型的行为又深受训练数据塑造。Karpathy 提醒，与其神化「问 AI」，不如把它理解为「在问一个平均水平的数据标注员」，因为助手的回答风格主要是模仿人工标注数据学来的。

工程含义。 别把模型输出当作经过核实的结论；对需要正确性的任务，用可验证的方式检查（测试、检索证据、规则校验）。

误区二：「把所有书原文存进去」

机制事实。 模型参数量远小于训练语料：Llama 3 405B 有 4050 亿参数，训练用了 15.6T token，无法逐字保存全部语料。模型学到的是统计规律的压缩表示，因此会遗忘细节，也会产生「幻觉」：生成看似合理但与事实或输入不符的内容。

但「完全不存原文」也不准确。 Carlini 等人从 GPT-2 中提取出数百段逐字的训练文本，包括电话、邮箱等个人信息，其中一些序列在训练数据中只出现在一篇文档里。后续研究发现，记忆程度随模型容量、样本重复次数和提示上下文长度的增加而显著上升。

更准确的说法是： 模型不是一个可检索的原文数据库，但会逐字记住部分内容，尤其是重复多次的文本。这同时带来隐私和版权风险，也是训练数据去重的理由之一。

误区三：「训练完还会自动学新知识」

机制事实。 部署后的模型权重是固定的。对话中提供的信息只存在于当次的上下文窗口里（in-context learning），会话结束就消失，不会写回权重。产品层面的「记忆」功能，本质上是把历史信息存在外部，再在需要时放回上下文。

怎样让模型用上新知识：

  • RAG（检索增强生成）：在生成时检索外部文档放进上下文。Lewis 等人指出，这种参数化与非参数化记忆的结合能提供来源依据，也便于更新知识。
  • 继续训练或微调：改变权重，但成本高，且少量 SFT 主要改变格式而非知识。

Karpathy 的概括很贴切：预训练用来获得知识，微调（监督或强化学习）用来养成习惯性行为，两者都要改参数；他认为还缺一种像人一样边用边学的学习范式。

工程实践与数字

  • 需要时效性和可追溯的知识：优先 RAG，并要求输出引用来源。
  • 涉及隐私数据的微调：注意记忆风险，做好去重和敏感信息过滤。
  • 关键决策输出：增加校验环节，不依赖模型「自信的语气」。

常见误区（小结）

误区 更准确的说法
像人一样理解 训练目标是预测下一个 token，能力来自数据中的模式
存了原文 主要是压缩学习，但会逐字记住部分内容
会自己学习 权重固定，新知识靠 RAG 或再训练
