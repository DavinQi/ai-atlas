预训练与规模定律：预测下一个 token，规模按幂律换来更低 loss

对应图 #6 · 第一章「大模型如何训练」

概述

预训练是整个流程中最昂贵的一步：在数万亿 token 上最小化下一个 token 的交叉熵。它最重要的经验规律是规模定律（scaling laws）：测试 loss 随参数量 N、数据量 D 和算力 C 平滑地按幂律下降，因此可以先用小模型拟合曲线，再预测大模型的表现并分配预算。

核心机制

1. 算力估算。 Kaplan 等人给出常用近似：每个训练 token 的非嵌入计算约为 6N FLOPs（前向 2N、反向 4N），总算力：

C≈6ND

2. Kaplan 幂律（2020）：

L(N)=(NNc​​)αN​,αN​≈0.076;L(D)=(DDc​​)αD​,αD​≈0.095

趋势跨越七个数量级以上；在较宽范围内，宽度与深度等结构细节影响很小。他们据此认为算力最优的做法是训练很大的模型、数据相对少、远在收敛前停下。

3. Chinchilla 修正（2022）。DeepMind 训练了 400 多个模型（7000 万到 160 亿以上参数，5B–500B token），拟合出：

L(N,D)=E+N0.34A​+D0.28B​,E=1.69, A=406.4, B=410.7

结论是：算力最优时，参数量和训练 token 数应同比例扩大，模型每翻一倍，数据也翻一倍。 据此训练的 Chinchilla（70B 参数、1.4T token）与 Gopher（280B）算力相同，却在大量下游任务上全面胜出，MMLU 平均 67.5%，比 Gopher 高出 7 个百分点以上。这个配比常被概括为「约 20 token / 参数」（1.4T ÷ 70B = 20）。

关键论文与里程碑

  • 2020 Kaplan scaling laws
  • 2020 GPT-3（175B）
  • 2021 Gopher（280B）
  • 2022 Chinchilla：揭示当时的大模型普遍「训练不足」。
  • 2024 Llama 3：用自己数据上的规模定律确定 405B 的尺寸。

工程实践与数字

  • Llama 3 405B：3.8×1025 FLOPs、15.6T token。报告称按其数据上的规模定律，这个尺寸在该预算下约为算力最优。用 C≈6ND 验算：6×4.05×1011×1.56×1013≈3.8×1025，两者吻合。
  • 为什么现在常「超量训练」？ Chinchilla 只优化训练算力。如果模型要服务海量推理请求，用更多 token 训练更小的模型，能降低每次推理的成本。Chinchilla 论文本身也指出更小的模型让微调和推理更省。
  • 并行训练：千亿级模型需要组合数据并行、张量并行和流水线并行（Megatron-LM），并用 ZeRO 切分优化器状态、梯度和参数以节省显存。

常见误区

  • 「涌现能力是突变。」 Wei 等人记录了在小模型上不出现、在大模型上出现的能力；但 Schaeffer 等人指出，很多「突变」源于不连续的评测指标，换成连续指标后曲线变得平滑可预测。
  • 「规模定律保证下游能力。」 幂律描述的是交叉熵 loss，下游任务分数与 loss 的关系要另行评估。
  • 「Kaplan 和 Chinchilla 互相否定。」 Chinchilla 论文认为差异部分源于 Kaplan 实验对所有模型使用了固定的学习率调度和训练 token 数；工程上更重要的是在自己的数据上重新拟合。
