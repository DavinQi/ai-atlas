后训练：从「会续写」到「会听指令、会推理」

对应图 #7 · 第一章「大模型如何训练」

概述

预训练得到的基座模型（base model）只会续写文本：问它一个问题，它可能接着再编几个问题，而不是回答。**后训练（post-training）**用比预训练少几个数量级的数据，把基座模型变成可用的助手。主流路线经历了三代演进：

  1. SFT：用高质量的「指令—回答」示范做监督微调，教会模型对话格式和基本的指令遵循。
  2. 偏好优化：用人类（或 AI）对多个回答的好坏比较，让模型更符合人的偏好。经典做法是 RLHF（奖励模型 + PPO），之后出现了更简单的 DPO。
  3. 可验证奖励的强化学习（RLVR）：在数学、代码等答案可自动判对错的任务上，直接用规则奖励做大规模 RL，激发长链推理。DeepSeek-R1 是代表。

核心机制

1. 监督微调（SFT）。 损失函数与预训练相同，都是下一个 token 的交叉熵，但只对「回答」部分计算损失，数据是人工编写或精选的示范。LIMA 只用 1000 条精选样本微调 65B 的 LLaMA，在人工对比中，43% 的情况下其回答与 GPT-4 相当或更好。作者据此提出「表层对齐假设」：知识几乎都在预训练中学到，SFT 主要教模型用什么格式和风格作答。

2. RLHF。 偏好学习的思路最早由 Christiano 等人在 2017 年的深度强化学习中提出，后在文本摘要任务上验证，再由 InstructGPT 系统化为三步：

  • 步骤一：SFT。 约 1.3 万条训练提示，由标注员撰写示范。
  • 步骤二：训练奖励模型（RM）。 约 3.3 万条提示，标注员对同一提示的多个输出排序。用 Bradley–Terry 模型把排序转成成对比较：

LRM​=−E(x,yw​,yl​)​[logσ(rϕ​(x,yw​)−rϕ​(x,yl​))]

其中 yw​ 为更受偏好的回答，yl​ 为较差的回答。

  • 步骤三：PPO 强化学习。 约 3.1 万条提示，最大化奖励，同时用 KL 惩罚防止策略偏离 SFT 模型太远：

πθ​max​ Ex,y∼πθ​​[rϕ​(x,y)]−βDKL​[πθ​(y∣x)∥πref​(y∣x)]

PPO 本身是 Schulman 等人提出的策略梯度算法，通过截断概率比来限制每次更新的幅度。InstructGPT 发现 RLHF 会让部分公开 NLP 基准的表现下降，称之为「对齐税（alignment tax）」，并通过在 PPO 中混入预训练梯度（PPO-ptx）来缓解。

3. DPO。 Rafailov 等人证明，上述带 KL 约束的目标有闭式最优解，奖励可以用策略自身表示，于是奖励模型和 RL 步骤都可以省掉，直接在偏好对上优化：

LDPO​=−E[logσ(βlogπref​(yw​∣x)πθ​(yw​∣x)​−βlogπref​(yl​∣x)πθ​(yl​∣x)​)]

论文报告，DPO 在情感控制上优于基于 PPO 的 RLHF，在摘要和单轮对话上效果持平或更好，实现和训练都简单得多，训练中也无需从模型采样。

4. RLVR 与 GRPO。 当答案能被程序检查（数学题核对最终答案、代码跑测试用例）时，奖励不再依赖可能被「钻空子」的奖励模型。Tulu 3 把这类方法命名为「可验证奖励的强化学习」（RLVR），并与 SFT、DPO 组成完整的开源后训练配方。

DeepSeekMath 提出的 GRPO 是 PPO 的变体：对同一提示采样一组回答，以组内奖励的均值和标准差做归一化，得到每个回答的优势值，从而省掉与策略同等规模的价值网络（critic），降低显存占用。

5. DeepSeek-R1 的流程：

  • R1-Zero：直接在 DeepSeek-V3 基座上做 RL，不经过 SFT。奖励全部基于规则（准确性奖励 + 格式奖励）。论文明确表示不对推理任务使用神经奖励模型，因为观察到它们在大规模 RL 中容易被 reward hacking。训练中 AIME 2024 的平均 pass@1 从 15.6% 升到 77.9%，用自一致性解码后达到 86.7%，并出现了自我反思、验证等行为（论文中称为「aha moment」）。
  • R1-Zero 的问题：可读性差，中英文混杂。
  • R1 的做法：先用数千条冷启动长思维链数据做 SFT → 推理 RL（加入语言一致性奖励）→ 拒绝采样生成新数据，与非推理数据一起再做 SFT → 第二阶段 RL，提升有用性和无害性。

工程实践与数字

  • 数据规模：InstructGPT 三个阶段分别约 1.3 万、3.3 万、3.1 万条提示，相对预训练的万亿级 token 可以忽略不计，但标注质量要求极高。
  • 工业配方：Llama 3 的后训练由 SFT、拒绝采样（用奖励模型从多个候选中挑最好的）和 DPO 多轮迭代组成，报告称选择 DPO 而不是 PPO 等更复杂的强化学习算法。
  • 开源可复现：Tulu 3 公开了基于 Llama 3.1 的完整数据、代码和配方（SFT → DPO → RLVR），是企业搭建自有后训练流程的最佳起点。
  • 选型建议：
    • 只需调整格式或风格：少量高质量数据做 SFT（可配合 LoRA 等参数高效方法）。
    • 需要对齐偏好：DPO 实现最简单、最稳定。
    • 需要提升推理正确率，且有可自动判分的任务：RLVR / GRPO。

常见误区

  • 「RLHF 是真正的强化学习，可以无限提升。」 Karpathy 认为 RLHF「只勉强算 RL」：奖励模型只是人类偏好的近似，不像围棋那样有客观胜负，优化久了模型就会找到骗过奖励模型的输出。这也是 R1 选用规则奖励的原因。
  • 「SFT 能灌入大量新知识。」 LIMA 的结论恰恰相反：SFT 主要教格式。
  • 「DPO 完全取代了 RL。」 DPO 用的是离线偏好数据。推理能力的大幅提升主要来自在线采样的 RL（如 GRPO + 可验证奖励）。
  • 「对齐是免费的。」 InstructGPT 记录了对齐税。
