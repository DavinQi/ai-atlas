后训练：从「会续写」到「会听指令、会推理」

对应图 #7 · 第一章「大模型如何训练」

预训练结束时，我们手里是一个读过万亿 token、知识渊博，却不太「好用」的基座模型。问它「法国的首都是哪里？」，它可能接着写「德国的首都是哪里？英国的首都是哪里？」；它可能一直写下去不知道停，模仿网上的粗鲁语气，或者对有害请求照单全收。知识已经在了，缺的是以助手身份回应的行为方式。

后训练（post-training）就是补上这一课，而且用的数据比预训练少几个数量级。图 #7 把主流路线画成四级台阶：01 SFT、02 RLHF、03 DPO、04 RLVR 推理强化。每一级回答的问题不同：怎样学会回答？怎样学会人喜欢的回答？怎样更便宜地学？怎样在有标准答案的题上越做越对？下面逐级拆开。

01 SFT：看示范学回答

做法。 收集「指令 + 优质回答」的示范，用和预训练完全相同的下一个 token 交叉熵继续训练。区别只有两点：数据是人写或精选的对话；损失只对「助手」部分计算，因为模型要学的是怎样回答，而不是怎样提问。

对话其实还是一段文本。 一轮对话会被整理成带特殊标记的格式，大致像这样（不同模型的标记各不相同）：

<|system|>你是一个乐于助人的助手。
<|user|>法国的首都是哪里？
<|assistant|>法国的首都是巴黎。<|end|>

所谓「系统提示词」，就是放在最前面的一段文字；多轮对话中，之前每一轮都会拼在一起作为下一轮的前文；模型学会了在回答完时生成结束标记，所以知道什么时候停。

数据要多少？ 比想象中少得多。InstructGPT 的 SFT 阶段约 1.3 万条训练提示。LIMA 更极端：只用 1000 条精选示范微调 65B 的 LLaMA，在人工对比中，有 43% 的情况其回答与 GPT-4 相当或更好。作者据此提出「表层对齐假设」：知识几乎都来自预训练，SFT 主要教模型用什么格式和风格作答。 这条假设有一个很实用的推论：想用少量 SFT 给模型灌进大量新事实，通常事倍功半。

局限。 示范的天花板是写示范的人。高质量示范很贵，而且在很多任务上，人更擅长比较而不是创作：你未必写得出一首好诗，但给你两首，大概分得出哪首更好。

02 RLHF：只告诉它「哪个更好」

基于人类反馈的强化学习（RLHF）利用的正是这一点。强化学习不给标准答案，只给打分，让模型自己尝试，往得分高的方向调整。偏好学习的思路最早由 Christiano 等人 2017 年在深度强化学习中提出，后在文本摘要任务上验证，再由 InstructGPT 系统化为三步：

第一步，SFT（同上）。

第二步，训练奖励模型（RM）。 约 3.3 万条提示，标注员对同一提示的多个输出排序。排序被拆成两两比较，用 Bradley–Terry 模型训练：

LRM​=−E(x,yw​,yl​)​[logσ(rϕ​(x,yw​)−rϕ​(x,yl​))]

读法很直观：yw​ 是更受偏好的回答，yl​ 是较差的回答，模型要让前者的分数比后者高；分差越大，σ 越接近 1，损失越小。奖励模型从此成了「人类评委的替身」，可以给无数新回答打分。

第三步，PPO 强化学习。 约 3.1 万条提示。模型生成回答 → 奖励模型打分 → 让高分回答更可能被生成。但有一个关键约束：

πθ​max​ Ex,y∼πθ​​[rϕ​(x,y)]−βDKL​[πθ​(y∣x)∥πref​(y∣x)]

后一项 KL 惩罚把模型拴在 SFT 模型 πref​ 附近。为什么要拴？因为奖励模型只是人类偏好的近似，有盲点。放开优化，模型会找到钻空子的写法：比如奖励模型略微偏爱长回答，模型就越写越长、越写越空。这叫奖励投机（reward hacking）。PPO 本身是 Schulman 等人提出的策略梯度算法，通过截断新旧策略的概率比，限制每次更新的幅度，同样是为了「别走太远」。

效果与代价。 在 InstructGPT 的人工评测中，1.3B 参数模型的输出比 175B 的 GPT-3 更受偏好。就好不好用而言，后训练可能和规模一样重要。但他们也记录了「对齐税」：RLHF 之后，部分公开 NLP 基准的表现会下降；他们通过在 PPO 中混入预训练梯度（PPO-ptx）来缓解。

Karpathy 对 RLHF 有一个常被引用的评价：它「只勉强算 RL」。围棋有客观的输赢，而 RLHF 的奖励只是对人类判断的一个可被欺骗的模拟，优化久了就会被钻空子。这正是下面两级台阶要解决的问题。

人类标注也可以部分换成 AI 反馈：Constitutional AI 用一组书面原则让模型自己给出批评与偏好（RLAIF），减少了有害性方面的人工标注。

03 DPO：把强化学习化简成一个分类损失

RLHF 的工程负担很重：要训一个奖励模型，要在线从策略采样，还要同时在显存里放下策略、参考模型、奖励模型和价值网络。Rafailov 等人发现，上面那个带 KL 约束的目标有闭式最优解，奖励可以用策略自身的概率比来表示，于是奖励模型和 RL 循环都可以省掉，直接在偏好对上优化：

LDPO​=−E[logσ(βlogπref​(yw​∣x)πθ​(yw​∣x)​−βlogπref​(yl​∣x)πθ​(yl​∣x)​)]

直观地说：提高较好回答相对参考模型的概率，降低较差回答的概率，β 控制能偏离参考模型多远，角色和 RLHF 里的 KL 系数一样。论文报告，DPO 在情感控制上优于基于 PPO 的 RLHF，在摘要和单轮对话上持平或更好，而训练中不需要从模型采样。正因为简单稳定，Llama 3 的后训练选择了 SFT + 拒绝采样 + DPO 的多轮迭代，报告明确说没有用 PPO 等更复杂的强化学习算法。

DPO 的代价是它用的是离线偏好数据：模型只能从已有的回答对里学，不能自己探索新的解法。

04 RLVR：只判对错，让模型自己摸索

数学题可以核对最终答案，代码可以跑测试用例。当答案能被程序检查时，奖励就不再依赖一个会被钻空子的奖励模型。Tulu 3 把这类方法命名为可验证奖励的强化学习（RLVR），并与 SFT、DPO 组成了完整公开的后训练配方。

GRPO：省掉价值网络。 PPO 需要一个和策略同等规模的价值网络（critic）来估计「这个回答比平均水平好多少」。DeepSeekMath 提出的 GRPO 换了个办法：对同一道题采样一组回答，用组内奖励的均值和标准差做归一化，直接得到每个回答的优势值。举个例子：同一道题采样 4 个回答，奖励分别是 1、0、1、0（对或错），均值 0.5、标准差 0.5，于是答对的两个优势为 +1，答错的为 −1，模型被推向前者、远离后者。不需要 critic，显存占用大幅下降。

DeepSeek-R1：推理是「练」出来的。 R1-Zero 直接在 DeepSeek-V3 基座上做 RL，不经过 SFT，奖励全部基于规则：答案对不对（准确性奖励）加上是否按规定格式写出思考过程（格式奖励）。论文明确表示不对推理任务使用神经奖励模型，因为观察到它们在大规模 RL 中容易被 reward hacking。训练中 AIME 2024 的平均 pass@1 从 15.6% 升到 71.0%（arXiv 初版；Nature 版本报告 77.9%），用多数投票后达到 86.7%。更有意思的是行为变化：回答越来越长，模型开始自发地复查、换一种思路、发现错误后回头修正，论文称之为「aha moment」。

R1-Zero 也有明显问题：可读性差，中英文混杂。于是正式的 R1 采用了四段式：先用数千条冷启动长思维链数据做 SFT → 推理 RL（加入语言一致性奖励）→ 用拒绝采样生成新数据，与非推理数据一起再做 SFT → 第二阶段 RL，提升有用性和无害性。这也说明四级台阶不是互相替代，而是组合使用。

如果要自己搭后训练流程，Tulu 3 公开了基于 Llama 3.1 的完整数据、代码和配方（SFT → DPO → RLVR），是很好的起点。

四个常见误解

  • 「RLHF 可以无限提升。」 奖励模型是近似，优化越久越容易被钻空子，所以才需要 KL 约束，推理任务也才转向规则奖励。
  • 「SFT 能灌入大量新知识。」 LIMA 的结论恰恰相反：SFT 主要教格式。
  • 「DPO 完全取代了 RL。」 DPO 用离线数据；推理能力的大幅提升主要来自在线采样的 RL。
  • 「对齐是免费的。」 InstructGPT 记录了对齐税，后训练总是在不同目标之间权衡。
