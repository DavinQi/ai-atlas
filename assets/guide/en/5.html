The Transformer: Attention Lets Each Token Gather Context by Relevance

Companion to diagram #5 · Chapter 1 "How LLMs Are Trained"

Overview

The 2017 paper Attention Is All You Need introduced the Transformer: no recurrence, no convolution — sequences modeled entirely with attention. Today's LLMs are almost all decoder-only variants: a stack of identical layers, each with a causal self-attention sublayer and a feed-forward network (FFN), plus residual connections and normalization. Attention lets each position pull information from earlier context according to relevance; the FFN applies a per-position nonlinear transform and is widely believed to hold much of the model's "stored knowledge".

Core Mechanisms

1. Scaled dot-product attention:

Attention(Q,K,V)=softmax(dk​​QK⊤​+M)V

with Q=XWQ​, K=XWK​, V=XWV​. Dividing by dk​​ keeps dot products from saturating the softmax. M is the causal mask: future positions are set to −∞, so token t only sees positions ≤t — which is exactly why autoregressive training can run in parallel.

2. Multi-head attention. Split d dimensions into h heads, compute attention per head, concatenate and project, so different heads can capture different relations.

3. Sharing KV heads. Multi-query attention (MQA) has all query heads share one set of K/V, greatly speeding up decoding; grouped-query attention (GQA) compromises with several shared groups, reaching quality close to multi-head attention at speed close to MQA. Llama 3 8B/70B/405B all use only 8 KV heads.

4. Modern components. Compared with the original, mainstream LLMs typically use:

  • Pre-norm + RMSNorm: root-mean-square scaling only, cheaper to compute.
  • SwiGLU FFN: a gated-linear-unit variant that performs better at equal compute.
  • RoPE positional encoding.

5. Complexity and FlashAttention. Standard attention is quadratic in sequence length in both time and memory. FlashAttention keeps the math unchanged (exact attention) but uses tiling to cut reads and writes between GPU high-bandwidth memory (HBM) and on-chip SRAM; the paper reports a 3× end-to-end training speedup on GPT-2 (sequence length 1K). FlashAttention-2 further improves parallelism and work partitioning.

Practical notes:

  • The long-context bottleneck is not just attention compute but KV-cache memory; GQA shrinks it directly by a factor of nkv​/nheads​.
  • Training and serving stacks (PyTorch SDPA, vLLM, etc.) ship FlashAttention-style kernels by default; reuse them rather than rolling your own.

Common Misconceptions

  • "Attention weights explain the model." Attention distributions reflect only part of the information routing and are not a causal explanation by themselves.
  • "A longer context window means the model uses all of it." Window length is an architectural and training limit; actual utilization must be evaluated separately.
  • "FlashAttention is an approximation." It computes exact attention, just in a different order and memory-access pattern.
