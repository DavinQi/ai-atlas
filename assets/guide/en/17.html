The Evolution of Programming: From Syntax, to Code, to Tasks

Companion to diagram #17 · Chapter 3 "The Evolution of Programming"

Overview

The history of programming can be read as a history of "what humans hand over to machines". Each leap removes a layer of detail from human attention: high-level languages freed people from machine instructions, IDEs and code completion reduced API memorization, AI completion cut boilerplate typing, and coding agents begin to shift people from "writing code" to "defining tasks and accepting results".

Core Mechanisms

The timeline falls into three stages, each with a different human focus:

1. Focus on syntax (high-level languages and IDEs).

  • 1957, FORTRAN: Backus et al. published The FORTRAN Automatic Coding System; a high-level language translated formulas into machine instructions.
  • 1995, Java: released in May 1995 as a core component of Sun's Java platform — "write once, run anywhere", with the JVM hiding platform differences.
  • 1996, IntelliSense: Microsoft's code completion first appeared in a mainstream Microsoft product in 1996 (Visual Basic 5.0 Control Creation Edition), using static analysis to suggest members and parameters.

2. Focus on code (AI completion and AI IDEs).

  • 2021, Codex and Copilot: OpenAI's Codex paper reports that on the newly released HumanEval benchmark Codex solved 28.8% of problems versus 0% for GPT-3; the paper also says GitHub Copilot is powered by a production version of Codex. On June 29 of that year GitHub launched the Copilot technical preview as an "AI pair programmer".
  • AI IDEs such as Cursor followed, extending the model from "completion at the cursor" to deep integration with the whole editor, multiple files and chat.

3. Focus on tasks (coding agents).

  • February 24, 2025: Anthropic released the command-line agentic coding tool Claude Code alongside Claude 3.7 Sonnet.
  • April 2025: OpenAI open-sourced Codex CLI, a lightweight coding agent that runs in the local terminal.
  • Agents no longer sit in the editor waiting for line-by-line instructions; they advance tasks autonomously in an "act — verify — correct" loop.

Key Papers and Milestones

  • 2021 Codex / HumanEval
  • 2023 SWE-bench: 2,294 tasks from real GitHub issues across 12 popular Python repositories; the best model at release, Claude 2, solved only 1.96%
  • 2024 SWE-agent: a computer interface designed for agents, reaching 12.5% pass@1 on SWE-bench
  • November 2024: MCP announced

Engineering Practice and Numbers

  • Benchmark evolution mirrors the shift in focus: HumanEval tests "write a function from a docstring"; SWE-bench tests "fix an issue in a real codebase", requiring coordinated changes across functions and files, interaction with an execution environment, and very long contexts.
  • Alibaba's AI Native R&D Paradigm Practice Handbook (annotated edition) records that by mid-2026 mainstream models' pass rate on SWE-bench Verified had risen from under 30% two years earlier to around 80%; industry consensus shifted accordingly — the bottleneck is no longer generating code but requirements understanding, environment setup, testing and verification, release and operations, which make up 70%–80% of the development lifecycle.

Common Misconceptions

  • "AI makes programming skills unimportant." Each rise in abstraction moves the weight to higher-level abilities: problem definition, architectural judgment and verification design.
  • "High benchmark scores mean it can deliver." The handbook states plainly that high benchmark scores do not equal real delivery capability in production.
  • "An agent is just an enhanced Copilot." The interaction models differ: completion is human-led, accepted line by line; with an agent, the human gives a task and reviews the result.
